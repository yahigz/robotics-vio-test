# Overleaf

1. Upload `vio-report-overleaf.zip` to Overleaf: New Project → Upload Project. It builds with pdfLaTeX out of the box.
2. Fill in the `% TODO` blocks in `main.tex`. Figures and the table are already included.
3. If results change, run `pixi run figures` in the repo root, then re-upload `figures/` and `tables/`, or rebuild the zip:
   `cd report/overleaf && zip -r ../vio-report-overleaf.zip main.tex figures tables`

| File | What it shows |
|---|---|
| `figures/traj_xy.pdf` | Top view of GT and the three methods on garden / campus / park (SE(3) alignment) |
| `figures/scale_se3_sim3.pdf` | APE with SE(3) vs Sim(3) alignment, s* above each bar: how much of the error is scale |
| `figures/ape_time.pdf` | APE over time (park y-axis clipped because of DBA-Fusion's start-up failure) |
| `figures/rpe_segments.pdf` | RPE over 10/20/50/100 m segments, boxplots (optional, if there's room) |
| `tables/results.tex` | Results table (booktabs, best value per sequence in bold) |
| `tables/orbslam3_runs.tex` | `\orbruns` macro with APE of the three ORB-SLAM3 runs |

All of these are generated by `report/make_figures.py`. It uses the same evaluation as `eval/evaluate.py`
(prism lever arm, interpolation at GT times, translation-only RPE).
